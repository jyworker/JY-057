# 快速启动指南

## 前置准备

1. ✅ 安装 JDK 17
2. ✅ 安装 Maven 3.6+
3. ✅ 安装 MySQL 8.0+
4. ✅ 安装 IntelliJ IDEA（推荐）

## 启动步骤

### 第一步：初始化数据库

在 MySQL 中执行建表脚本：

```bash
# 方式一：命令行
mysql -u root -p < database/schema.sql

# 方式二：MySQL Workbench 或 Navicat
# 打开 database/schema.sql 文件并执行
```

**重要**：脚本会自动创建数据库 `hug_mom` 并插入测试数据。

---

### 第二步：修改数据库配置

编辑 `src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    username: root
    password: 你的数据库密码  # ← 修改这里
```

---

### 第三步：导入并启动项目

#### 方式一：使用 IDEA（推荐）

1. **打开 IDEA** → `File` → `Open` → 选择 `D:\Java\hugging_mother\back` 文件夹
2. **等待 Maven 依赖下载**（首次启动会比较慢，请耐心等待）
3. **找到启动类** `src/main/java/com/hugmom/back/BackApplication.java`
4. **右键运行** → `Run 'BackApplication'`

#### 方式二：使用 Maven 命令

```bash
cd D:\Java\hugging_mother\back

# 编译打包
mvn clean install

# 启动项目
mvn spring-boot:run
```

---

### 第四步：验证启动

启动成功后，控制台会输出：

```
========================================
  拥抱妈妈·爱在平安 后端服务启动成功！
  AI向善 · 技术隐形于爱
  访问地址: http://localhost:8080
========================================
```

**测试接口**：

在浏览器或 Postman 中访问：

```
http://localhost:8080/api/family/members
```

如果返回 JSON 数据（包含测试成员），说明启动成功！

## 常见问题

### Q1: Maven 依赖下载失败？

**解决**：配置阿里云镜像

编辑 `~/.m2/settings.xml`（如果没有则创建）：

```xml
<settings>
  <mirrors>
    <mirror>
      <id>aliyun</id>
      <mirrorOf>central</mirrorOf>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
</settings>
```

---

### Q2: 数据库连接失败？

**检查项**：
1. MySQL 服务是否启动？
2. 用户名密码是否正确？
3. 数据库 `hug_mom` 是否已创建？

**测试连接**：

```bash
mysql -u root -p
USE hug_mom;
SHOW TABLES;
```

---

### Q3: Lombok 注解不生效？

**解决**：
1. IDEA 安装 Lombok 插件
2. 启用注解处理器：
   - `Settings` → `Build, Execution, Deployment` → `Compiler` → `Annotation Processors`
   - 勾选 `Enable annotation processing`

---

### Q4: 端口 8080 被占用？

**解决**：修改端口

编辑 `application.yml`：

```yaml
server:
  port: 8081  # 改为其他端口
```

同时记得修改前端的 API 地址。
