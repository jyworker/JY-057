# 微信登录功能使用说明

## 🎉 功能完成清单

### ✅ 后端已完成

1. **JWT Token 生成与验证**
   - 使用 JJWT 库生成安全的 Token
   - Token 有效期：7天（可配置）
   - 支持 Token 验证和解析

2. **微信 API 集成**
   - 实现 `code2session` 接口调用
   - 获取用户 `openid`
   - 支持开发模式和生产模式切换

3. **登录流程**
   - 接收前端的微信 `code`
   - 调用微信 API 换取 `openid`
   - 查询或创建用户
   - 生成 JWT Token 返回

4. **Token 拦截器**
   - 自动验证请求中的 Token
   - 将 `userId` 注入到请求属性中
   - 所有 API 接口（除登录外）都需要携带 Token

### ✅ 前端已完成

前端代码已经写好，包括：
- 调用 `wx.login()` 获取 `code`
- 发送 `code` 到后端
- 存储返回的 `token` 和 `userInfo`
- 在后续请求中携带 Token

## 🚀 使用方式

### 开发环境（当前配置）

**配置文件**：`application.yml`

```yaml
wechat:
  mini:
    enable: false  # 关闭真实微信登录
```

**行为**：
- 不调用微信 API
- 使用模拟 `openid`
- 可以直接在浏览器测试

**测试步骤**：

1. 启动后端服务
2. 使用 Postman 测试登录接口：

```bash

Content-Type: application/json

{
  "code": "test123"
}
```

**返回示例**：

```json
  "msg": "登录成功",
```

3. 使用返回的 Token 访问其他接口：


## 🔐 Token 使用说明

### Token 格式

```
Authorization: Bearer <token>
```

### Token 有效期

- 默认：7天（604800000 毫秒）
- 可在 `application.yml` 中修改：

```yaml
hugmom:
  token:
    expire-time: 604800000  # 7天（毫秒）
```

### Token 验证

所有 API 接口（除登录外）都需要携带 Token，否则返回 401 错误：

```json
{
  "code": 401,
  "msg": "请先登录",
  "data": null,
  "success": false
}
```

### Token 验证接口（可选）

可以使用以下接口验证 Token 是否有效：

```bash
GET http://localhost:8080/api/auth/validate
Authorization: Bearer <token>
```

**返回**：

```json
{
  "code": 200,
  "msg": "Token有效",
  "data": {
    "valid": true,
    "userId": "user_abc123"
  },
  "success": true
}
```

## 📱 前端使用示例

### 登录流程

```typescript
// 1. 调用微信登录
const { code } = await wx.login()

// 2. 发送到后端
const result = await login({ code })

// 3. 保存 Token
wx.setStorageSync('token', result.token)
wx.setStorageSync('userInfo', result.userInfo)

// 4. 后续请求自动携带 Token（request.ts 已实现）
const members = await getFamilyMembers()
```

前端的 `request.ts` 已经自动处理 Token：

```typescript
// 自动从缓存中获取 Token
const token = wx.getStorageSync('token') || ''

// 自动添加到请求头
header: {
  'Authorization': token ? `Bearer ${token}` : ''
}
```

## 🔧 常见问题

### Q1: Token 过期怎么办？

**后端返回**：

```json
{
  "code": 401,
  "msg": "Token无效或已过期，请重新登录",
  "success": false
}
```

**前端处理**：

`request.ts` 已经自动处理 401 错误，会：
1. 清除本地缓存
2. 提示"请先登录哦"
3. 跳转到登录页

### Q2: 如何在开发环境测试？

**方法一**：使用 Postman

1. 调用登录接口获取 Token
2. 复制 Token
3. 在其他接口的 Header 中添加：`Authorization: Bearer <token>`

**方法二**：使用前端小程序

1. 启动后端服务（`wechat.mini.enable: false`）
2. 在微信开发者工具中启动前端
3. 点击"登录"按钮
4. 前端会自动使用模拟 code 登录

### Q3: 如何切换到生产环境？

修改 `application.yml`：

```yaml
wechat:
  mini:
    enable: true  # 改为 true
    appid: wxXXXXX  # 填入真实 AppID
    secret: XXXXX   # 填入真实 AppSecret
```

重启后端服务即可。

### Q4: Token 密钥安全吗？

当前使用的密钥：`hugmom-ai-for-good-2026`

**生产环境建议**：
- 使用更复杂的密钥（至少32位）
- 定期更换密钥
- 不要将密钥提交到代码仓库

可以使用以下命令生成随机密钥：

```bash
# Linux/Mac
openssl rand -base64 32

# PowerShell
[Convert]::ToBase64String((1..32 | ForEach-Object { Get-Random -Minimum 0 -Maximum 256 }))
```
