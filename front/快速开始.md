# 快速开始指南

## 5分钟上手

### 第一步：安装依赖

```bash
cd front
npm install
```

### 第二步：编译TypeScript

```bash
npm run compile
```

### 第三步：配置AppID

编辑 `project.config.json`，修改 `appid` 为你的测试AppID：

```json
{
  "appid": "你的测试AppID"
}
```

### 第四步：导入微信开发者工具

1. 打开微信开发者工具
2. 选择"导入项目"
3. 项目目录选择 `front` 文件夹
4. 点击"编译"

🎉 项目运行成功！

## 核心功能演示

### 1. 登录流程

```
登录页 → 点击"微信授权登录" → 获取Token → 跳转首页
```

### 2. 虚拟拥抱

```
首页 → 点击健在成员 → 拥抱页 → 长按屏幕 → 震动反馈 → 松开 → 提示"拥抱已送达"
```

### 3. 纪念空间

```
首页 → 点击已故成员 → 纪念空间 → 查看照片/写留言
```

### 4. 报平安

```
首页 → 点击"报平安" → 输入消息 → 暖心词自动高亮 → 发送
```

## 常见问题

### Q: 编译报错？

```bash
# 删除node_modules重新安装
rm -rf node_modules
npm install
npm run compile
```

### Q: 真机预览白屏？

检查：
1. API地址是否正确
2. 服务器是否启动
3. 网络是否通畅

### Q: 震动不生效？

检查：
1. 手机是否开启震动
2. 用户设置中是否开启震动反馈
